# Upgrading to Ultracite v6

Ultracite v6 split the single Biome preset into a `core` preset and one preset per framework, which a project combines in `extends`.

## Does the project need it?

Yes, if a Biome config (`biome.json` or `biome.jsonc`) extends the bare `ultracite` preset: `"extends": ["ultracite"]`.

## Steps

1. Replace `"ultracite"` in `extends` with `ultracite/core`, followed by the preset for each framework the project uses, judging by its `package.json` dependencies:

   | Dependency | Preset |
   | --- | --- |
   | `react` | `ultracite/react` |
   | `next` | `ultracite/next`, after `ultracite/react` |
   | `solid-js` | `ultracite/solid` |
   | `vue` | `ultracite/vue` |
   | `svelte` | `ultracite/svelte` |
   | `@builder.io/qwik` or `@qwik.dev/core` | `ultracite/qwik` |
   | `@angular/core` | `ultracite/angular` |
   | `@remix-run/react` | `ultracite/remix` |
   | `astro` | `ultracite/astro` |

   Keep every other setting in the file.

   ```jsonc title="biome.jsonc"
   {
     // v5: "extends": ["ultracite"]
     "extends": ["ultracite/core", "ultracite/react", "ultracite/next"],
   }
   ```

2. These are the v6 preset names. When you're upgrading to v7 or later, follow the v7 guide too, or write the v7 names (`ultracite/biome/core`, `ultracite/biome/react`, and so on) directly.

## Check

`npx ultracite check` runs without a configuration error.
